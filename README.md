# PinkChat FINAL

Готовая PWA-версия мессенджера: вход по имени и паролю, личные чаты по имени, фото, эмодзи, редактирование/удаление сообщений, профили, темы, истории и админ-панель.

## Запуск

1. Загрузить всё содержимое этой папки в корень GitHub-репозитория.
2. В Supabase → SQL Editor запустить целиком `supabase/schema.sql`.
3. В Supabase → Authentication → Providers → Email отключить **Confirm email**. Это обязательно, потому что PinkChat создаёт внутренний технический email автоматически, а пользователь видит только имя и пароль.
4. В GitHub: Settings → Pages → Source: **GitHub Actions**.
5. Зарегистрироваться в приложении.

## Назначить администратора

После регистрации открыть SQL Editor и запустить `supabase/MAKE_ADMIN.sql`. Внутри можно заменить имя `Томша Евгений` на любое точное имя зарегистрированного аккаунта.

Пароль администратора задаётся при обычной регистрации и нигде в открытом коде не хранится.
